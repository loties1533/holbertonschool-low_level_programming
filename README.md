# Holberton School - Low Level Programming (C)

Collection de projets réalisés en langage **C** dans le cadre de la formation à Holberton School Bordeaux.

Ce dépôt couvre les bases et les concepts avancés du **langage C**, notamment la gestion de la mémoire, les pointeurs, les structures de données et la manipulation de fichiers.

---

##  Description

Ce repository regroupe plusieurs projets permettant d'apprendre les concepts fondamentaux et avancés de la programmation en **C**.

Les projets abordent :

* la gestion de la mémoire
* les pointeurs et tableaux
* les listes chaînées
* les fonctions et boucles
* les structures
* les fichiers
* les fonctions variadiques

---

##  Objectifs

* Comprendre le fonctionnement de la mémoire
* Maîtriser les pointeurs et tableaux
* Implémenter des structures de données en C
* Appliquer les bonnes pratiques de programmation
* Respecter le **style Betty** pour le code C

---
